# Migration Project Configuration — wordpress eval fixture

This file provides project-specific values for the generic `drupal-migrate-*` skills.
It is the fixture copy of `references/project-config.template.md`: the eval scaffold
installs it at `.agents/references/migrate/project-config.md` in the run workspace.

The source is a synthetic database generated by `evals/fixtures/generate.py` from
`evals/fixtures/wordpress/spec.json`. Nothing in it comes from a real site.

## Database Connection

The source is a **raw dump imported into a database container**. There is no
`wp-config.php` and no `wp` CLI: the only way to read the source is the read-only runner
below, which connects as a database user that holds `SELECT` only and refuses any
statement that is not `SELECT`, `SHOW`, `DESCRIBE`, `EXPLAIN` or `WITH`. The identifier
is the table prefix, not a database key.

### Connection command

Run every query through the fixture runner, one statement per call. In the eval
workspace the scaffold installs the runner as `.agents/bin/fixture` and rewrites the
commands below to that path; outside it, call
`plugins/drupal-migrate/evals/fixtures/bin/fixture` from the `sf-agents-harness` checkout.

```bash
fixture query wordpress 'SELECT 1'
```

Substitute this command wherever a skill shows a `wp db query` or `ddev wp db query`
example. Use `DATABASE()` in `INFORMATION_SCHEMA` lookups; the runner already selects
the `wordpress` schema.

### Enabling migration mode (optional)

Start the fixture before any query:

```bash
fixture up wordpress
fixture status
```

`fixture up` is idempotent. `fixture down wordpress` removes the container.
