# Migration Project Configuration — drupal7 eval fixture

This file provides project-specific values for the generic `drupal-migrate-*` skills.
It is the fixture copy of `references/project-config.template.md`: the eval scaffold
installs it at `.agents/references/migrate/project-config.md` in the run workspace.

The source is a synthetic database generated by `evals/fixtures/generate.py` from
`evals/fixtures/drupal7/spec.json`. Nothing in it comes from a real site.

---

The source is the fixture site `www.drupal7.example`, a **Drupal 7 single site** in
English. Only the database was delivered, imported into a MariaDB container named
`dm-fixture-drupal7`, schema `drupal7`. There is one source database; its key is
`drupal7`. The major version, 7, comes from the delivery notes; the exact core release is
not part of the delivery.

## Database Connection

The source is a **raw dump imported into a database container** (the "Other CMS / raw
dump" access path of the template). There is no settings file and no site CLI: the
only way to read the source is the read-only runner below, which connects as a
database user that holds `SELECT` only and refuses any statement that is not
`SELECT`, `SHOW`, `DESCRIBE`, `EXPLAIN` or `WITH`.

### WordPress source (delete if the source is Drupal)

Not applicable: the source is Drupal.

### Configuration in settings.php (Drupal source)

Not applicable: DB-only delivery, no settings file. The connection is owned by the

### Connection details

| Parameter              | Value                                          |
| ---------------------- | ---------------------------------------------- |
| Database key (primary) | `drupal7`                                      |
| Schema name            | `drupal7`                                      |
| Host                   | container `dm-fixture-drupal7` (MariaDB 10.11) |
| Read-only user         | `reader` (`SELECT` only)                       |
| Runner option          | fixture name `drupal7`                         |

### Connection command

Run every query through the fixture runner, one statement per call. The command is on
`PATH` in the eval workspace; outside it, call
`plugins/drupal-migrate/evals/fixtures/bin/fixture` from the `sf-agents-harness` checkout.

```bash
fixture query drupal7 'SELECT 1'
```

Substitute this command wherever a skill shows a site-CLI query example. Use
`DATABASE()` in `INFORMATION_SCHEMA` lookups; the runner already selects the `drupal7`
schema.

### Enabling migration mode (optional)

Start the fixture before any query:

```bash
fixture up drupal7
fixture status
```

`fixture up` is idempotent. `fixture down drupal7` removes the container.
